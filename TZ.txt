2. LOYIHA MAQSADI
==================================================

QuietSpace Tashkent — Toshkent shahrida masofadan ishlaydiganlar,
freelancerlar va talabalar uchun tinch, qulay va ishlashga mos
joylarni topish, solishtirish, AI yordamida tavsiya olish va
kerak bo'lganda joyni bron qilish imkonini beruvchi web-platforma.

Platformada foydalanuvchi:
- Kafelar, kutubxonalar, coworkinglar va bepul ish zonalarini topadi.
- Xarita orqali joylarni ko'radi.
- Wi-Fi tezligi, shovqin darajasi, rozetkalar va narxlarni solishtiradi.
- Hozirgi bo'sh joylar sonini ko'radi.
- AI yordamida o'ziga mos joylarni topadi.
- Joy haqida batafsil ma'lumot va reviewlarni ko'radi.
- Kerak bo'lganda joyni bron qiladi.
- Booking qilish uchungina ro'yxatdan o'tadi yoki login qiladi.

14. DJANGO REST FRAMEWORK API

API format:

 /api/

AUTH:

POST /api/auth/register/
POST /api/auth/login/
POST /api/auth/refresh/
GET  /api/auth/me/

PLACES:

GET    /api/places/
GET    /api/places/<id>/
POST   /api/places/
PATCH  /api/places/<id>/
DELETE /api/places/<id>/

REVIEWS:

GET    /api/places/<id>/reviews/
POST   /api/places/<id>/reviews/
PATCH  /api/reviews/<id>/
DELETE /api/reviews/<id>/

BOOKINGS:

POST   /api/bookings/
GET    /api/bookings/my/
GET    /api/bookings/<id>/
PATCH  /api/bookings/<id>/cancel/

FAVORITES:

GET    /api/favorites/
POST   /api/favorites/<place_id>/
DELETE /api/favorites/<place_id>/

AVAILABILITY:

GET /api/places/<id>/availability/

AI:

POST /api/ai/recommend/

ADMIN:
Admin uchun Django Admin va kerak bo'lsa alohida admin API ishlatiladi.
